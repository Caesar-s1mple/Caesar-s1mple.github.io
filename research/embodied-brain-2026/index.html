1 · 总览:四个核心判断

先把结论放前面。过去两年(2024-01 ~ 2026-09)具身智能从「RT-2 刚证明 VLM 能出动作」 走到了「人形机器人进厂进家试点」,四件事值得记住:

~30 万小时全球机器人操作数据估计,vs LLM 文本 300 万亿 token
0–5.5%Claude 直接控制机械臂成功率(Anthropic 自测)
79% vs 49%VSI-Bench 空间智能:人类 vs 当时最强模型
5000 台智元 2025-12 量产下线,国产本体规模之最
① 技术已收敛

路线之争基本结束:VLA 是主干(action 从离散 token 收敛到 flow-matching/diffusion 专家), 分层「慢脑+快手」是人形场景事实标准(Helix、GR00T、GO-1、Gemini Robotics 全是双系统), 世界模型退居数据引擎与规划层,不再当控制器。

② 卡脖子的是数据不是算法

缺口 3–6 个数量级,且是结构性的:只有成功演示没有失败轨迹、没有触觉力觉、 人视频与机器人视角对不齐、license 碎片化。2026 年的分水岭是谁先跑通 「部署→收失败→自动标注→更新」的数据飞轮。

③ 评测处于危机状态

仿真三巨头被刷穿(LIBERO 高分在物体移动 2cm 后归零)、真机无统一协议、 成功率各家自报不可比。最深刻的发现来自 EmbodiedBench:很多高层任务上 去掉视觉输入分数不降——VLM 在「看见但不用」地蒙答案。

④ 空间感知是公共瓶颈

VSI-Bench(人 79% vs 模型 49–69%)、MMSI-Bench(人 97% vs GPT-5 40%)、 PerceptionBench(无模型过 60%,幻觉最弱)三份独立证据指向同一结论: 大脑的眼睛跟不上嘴和手。

3 · 怎么做:三条路线与 2026 年的收敛

端到端 VLA、分层大小脑、世界模型——2026 年它们不是三选一,而是融合成同一个栈。

3.1 端到端 VLA:action 表示的两次迭代

VLA 的思想实验由 RT-2(2023-07)完成:把连续动作离散成 256 个 bin、借用语言词表输出, web 数据和机器人数据 co-fine-tune,未见过的 emergent 技能 62% vs RT-1 的 32%—— 「web 知识可以迁移到控制」从此成立(数字来自 Google 论文)。之后的两年是 action 表示的两代演进:

3.2 分层「大脑/小脑」:人形场景的事实标准

高频控制等不起大模型推理(Claude 推理 ~0.2–0.4Hz,而直接关节控制需 ~83Hz——Anthropic 实测), 于是「慢脑规划 + 快手执行」成为人形与双臂场景的统一答案:

  • Figure Helix(2025-02):S2 = 7B VLM(7–9Hz)输出 latent,S1 = 80M 视觉运动策略(200Hz),单组权重控 35 自由度上半身;2026-01 Helix 02 再加 S0(1kHz 全身控制,替换 10.9 万行手写 C++)。无任何标准 benchmark 数字,只有 demo。
  • NVIDIA GR00T N1(2025-03):S2 = Eagle-2 VLM(1.34B,~10Hz),S1 = DiT + flow-matching(~120Hz),全开放权重;78 万条 Isaac Sim 合成轨迹,合成+真机比纯真机 +40%(自报)。
  • 智元 GO-1(ViLLA)(2025-03):VLM(InternVL-2B)+ Latent Planner(从人类视频无监督学 Latent Action Tokens)+ Diffusion Action Expert;平均成功率 46%→78%,其中 Latent Planner 单项 +12%(自报);2025-09 开源。
  • Gemini Robotics-ER(2025-03):Google 的「外置脑」——2D pointing、3D 检测、抓取点、轨迹规划,可接任意低层控制器;ER 1.5(2025-09)经 Gemini API 公开。
  • 字节 Robix(2025-09):李航带队,基于 Qwen2.5-VL 的高层认知层(2000 亿 token 三阶段训练),低层交 VLA 执行;真机任务完成率 92.6%(自报,Gemini 2.5 Pro 91.0%、GPT-4o 64.3%)。

两系统的接口没有共识:Helix 用 latent,GO-1 用 latent action tokens,Robix/ER 偏向文本与结构化指令。 高层错误会级联到小脑,而高层「大脑」本身的空间推理短板(第 8 节)直接封顶整个系统。

3.3 世界模型:从「当控制器」退到「造数据、做规划」

UniPi(2023)的「先生成计划视频、再逆推动作」原教旨路线,因像素生成太贵太慢基本被放弃。 但它的思想分化成两个真正落地的角色:

  • 数据引擎:NVIDIA Cosmos(2000 万小时视频训练)+ GR00T-Mimic/Dreams 管线,11 小时生成 78 万条合成轨迹 ≈ 6500 小时人类演示(NVIDIA 自报),GR00T N1 合成+真机提升 40%,N1.5 开发周期从 ~3 个月缩到 ~36 小时(自报);银河通用 GraspVLA 用 10 亿帧纯合成数据预训练,sim2real 直迁零样本抓取 ~90%、透明物体 86.6%(AnyGrasp 仅 10%,论文数字)。
  • latent 规划器:Meta V-JEPA 2(2025-06,LeCun 路线)——1.2B JEPA 预测 latent 而非像素,100 万+ 小时视频 + 仅 62 小时 DROID 机器人数据,真实 Franka 未见环境零样本抓取 65–80%(自有设置),规划耗时 16 秒 vs Cosmos 类方案 4 分钟。

2026 年的新信号是 1X 正式成立 World Model Lab 并放话「fine-tune 不出 AGI」—— 世界模型作为自我改进机制(生成视频学新任务)的赌局仍在加码; 而 Genie 3(2025-08)展示了实时交互世界生成的上限,但尚未接机器人控制。

3.4 收敛之后,各自未解决的问题

路线未解决的核心问题
端到端 VLA长时序误差累积与失败恢复弱;纯模仿学习 OOD 卡死;依赖昂贵真机数据;成功率自报不可比
分层架构系统间接口(latent/文本/waypoint)无共识;高层错误级联;大脑空间推理短板封顶
世界模型像素生成成本高、物理一致性(接触/摩擦)弱;作为控制器未验证;作为评测环境无协议
共同人类视频/失败数据变不成监督信号(缺 retargeting 与奖励接口);数据飞轮没人完全跑通

4 · 海外进度:OpenAI 零模型,Anthropic 只评测,Google 全栈

直接回答「Claude 他们、GPT 他们做到哪了」:两家大模型公司在具身上都还没有模型产品,但姿态完全不同。

4.1 Google DeepMind:唯一全栈玩家

模型线四代同堂:Gemini Robotics / ER(2025-03,arXiv:2503.20020)→ On-Device(2025-06,首个纯端侧 Gemini VLA,ALOHA/Franka/Apollo,50–100 条演示适配)→ 1.5 / ER 1.5(2025-09,双模型「先思考后行动」,ER 1.5 当天起 API 开放)→ 2 / ER 2 / On-Device 2(2026-07,全身控制+五指手,ER 2 支持连续视频理解与多机协作)。 配套:Genie 3 世界模型、ASIMOV 安全评测集、Apptronik/Boston Dynamics/Agility 合作。

⚠️ 注意 Google 的评测口径。ER 1.5 宣称的「15 个 benchmark 聚合分超 60、领先 GPT-5」, 那 15 个 bench(Point-Bench、RefSpatial、RoboSpatial、Where2Place、BLINK、CV-Bench、ERQA、EmbSpatial、 MindCube、SAT、Cosmos-Reason1、OpenEQA、VSI-Bench 等)全是感知/认知层,没有一个是动作成功率; 而 GR 2 的「拧灯泡 92%」是单任务演示数字。感知套件 + 单任务演示的组合拳,正是「评测混乱」的高级形态—— 它比同行认真,但仍不可横向比较。

4.2 OpenAI:零机器人模型,用钱和「规划脑 API」维持存在

  • 2024-05 重启机器人团队,2024-11 聘 Meta AR 硬件负责人 Kalinowski 主管;2026-03 Kalinowski 辞职(后加入 Anthropic)。两年间无模型发布。
  • 与 Figure 的合作(2024-02,$675M 轮)以 Figure 2025-02 宣布「机器人 AI 必须垂直整合,不能外包」告终——这是「大模型当外置脑」路线最响的一次耳光,也直接催生了 Helix。
  • 资本存在:OpenAI 创业基金 2023 领投 1X($23.5M)、参投 Physical Intelligence(2024-11,$400M 轮)。
  • GPT 系在机器人里的实际角色:Figure 01 的语音对话、1X NEO 的语音交互,以及被各家当真机对照组(Robix:GPT-4o 64.3% vs Robix-32B 92.6%,字节自报)。

4.3 Anthropic:零机器人模型,但贡献了全行业最诚实的自测

  • Project Fetch(Phase 1,2025-11):非机器人专家用 Claude 给 Unitree Go2 编程取物,完成时间约为对照组一半,但 Claude 无法独立完成任务;Phase 2(2026 年中):Opus 4.7 在 Claude Code 中自主运行,比最快人类组快约 20 倍,但闭环物理控制(精确推球)仍失败。
  • 「How Claude performs on robotics tasks」(2026-07,Frontier Red Team):MuJoCo 经典控制 + 真机行走 + Franka LIBERO 操作。直接关节控制成功率 0–5.5%;模型推理 ~0.2–0.4Hz vs 直接控制所需 ~83Hz;接入监督训练 VLA + 光标工具后操作成功率 6%→32%;官方结论:「模型学的是特定动作序列,还不是通用规划器」。
  • 2026 年 OpenAI 前机器人负责人 Kalinowski 加入,方向未公开。Anthropic 的姿态很清楚:不做 VLA,但把「通用 LLM 离机器人有多远」量化给全行业看。

4.4 NVIDIA:卖铲人的完整闭环

芯片(Jetson Thor)+ 仿真(Isaac Sim/Lab)+ 世界模型数据工厂(Cosmos)+ 开放基座(GR00T N1→N1.5→N1.7,2026 年 N1.7 号称首个 Apache 2.0 商用许可)。 GR00T N1.5 自报真机语言跟随 46.6%→93.3%、总成功率 43.3%→83.0%(GR-1 自有设置)。 「把数据问题变成算力问题」是这条路线的核心赌注。GR00T N2 的状态传言不一(本文标注未能核实)。

5 · 国内进度:Qwen 是隐形底座,开源大脑进入第一梯队

直接回答「Qwen 他们进度如何」——分两层:阿里自己下场(RynnBrain),和全行业把 Qwen-VL 当基座。

6.2 四个结构性缺口

  • 只有成功,没有失败:主流数据集全是专家演示;Eval-Actions(2026-01)专门收 2.8K 条失败轨迹才成新闻。没有失败,RL 自改进和「恢复」能力就没有监督来源——π*0.6 的 RECAP 本质就是在自产失败信号。
  • 没有触觉/力觉:OXE/DROID/AgiBot 主体均无;Figure 03 把指尖触觉(3g 力感知)当卖点,恰说明它是稀缺品。
  • 人视频对不齐机器人视角:人手与机械臂的形态差、2D 视频恢复 3D 运动之难,使「拿 YouTube 教机器人」至今主要靠掩码/重定向技巧(EgoMimic、H2R 用渲染机械手替换真人手,成功率 +5–23%)。
  • License 碎片化:DROID 可商用、AgiBot NC、Ego4D 研究专用、OXE 子集各自为政——2026 年「数据护城河」讨论升温,合规可用的数据比公开数据少得多。

6.3 三条补数路线

便携采集(无机器人采数)

UMI(手持夹爪+GoPro+SLAM):~111 demos/h,3 倍于 ALOHA 遥操作;Fast-UMI 去 SLAM 依赖;DexCap 专攻灵巧手。本质:把「人」变成移动数采终端。

合成数据(数据问题变算力问题)

MimicGen:200 条演示→5 万条;GraspVLA SynGrasp-1B:10 亿帧纯合成、sim2real 直迁 ~90%;NVIDIA Cosmos/GR00T-Dreams:11 小时造 78 万条轨迹(自报)。NVIDIA 路线的核心赌注。

人视频预训练

GR-2:3800 万互联网视频片段做视频预测预训练再微调动作;VPP 同类;GO-1 的 Latent Planner 从人类视频无监督学潜动作。利用的是唯一「无限」的数据源。

判断:三条路线都在验证中,但各自有解决不了的部分——合成数据解决不了触觉与接触物理, 人视频解决不了动作标签,便携采集解决不了规模。所以 2026 年的共识是 数据飞轮:部署真实本体 → 回收失败与边缘 case → 自动标注 → 回流训练。 谁先跑通,谁把「数据竞赛」变成「部署密度竞赛」——这也是智元 5000 台、银河通用 100+ 药店、 1X 家庭试点在战略上的真正含义。

7 · Benchmark:一场三层评测危机

仿真层被刷穿、真机层没协议、感知/认知层刚起步且各自为政。看具身数字前先看他是在哪一层报的。

7.1 仿真层:高分≈记忆

Bench地位危机证据
LIBERO(2023)VLA 论文标配;OpenVLA 76.5% → 2026 榜首 ~97%LIBERO-PRO(2025-10):95%+ 的模型在物体移动 2cm 后成功率归零;LIBERO-Plus:模型可完全无视语言指令——高分是记忆不是泛化

7.2 真机层:没有协议,RoboArena 是最认真的补丁

真机评测的现状是「每家自定义任务自报成功率」:GR-2 报 105 任务 97.7%、GR00T N1.5 报 83.0%、 腾讯报日化工厂 >95%、千寻报产线 99%——任务、本体、起始条件全不同,这些数字一个都不能横向比。 2025-06 的 RoboArena(类 Chatbot Arena:双盲 A/B、ELO 排名、0–100 部分进度分, 7 机构 600+ episodes)是目前最被认可的折中;2026 年两篇审计论文进一步指出: 跨论文引用头条数字的 setup 普遍不兼容、成功率差异的统计显著性普遍不达标、 二元成功率掩盖执行质量与「真自主还是遥控」的来源歧义。

7.3 感知/认知层:刚起步,但已有三个「皇帝新衣」级发现

  • 「看见但不用」(EmbodiedBench,2025-02):去掉视觉输入,MLLM 在高层任务上分数几乎不降(56.3→58.0),低层任务崩塌(57.7→17.4)——高层「具身推理」很多时候是靠文本先验蒙。
  • 「空间盲」(OpenEQA,CVPR'24):空间类问题上 VLM 与纯文本 LLM 打平;总分人类 85.9 vs GPT-4V 48.5。
  • 「协作鸿沟」(PARTNR,Meta 2024-11/2025-02):人机协作任务 AI ~30% vs 人类 93%,且 LLM 机器人与人搭档比双人组多耗 1.5 倍步数——少数公开可复现的人机对比。

这一层的 bench 正在快速涌现:ERQA(Google 自建 400 题多选,首发 Gemini 2.0 Pro 48.3 / GPT-4o 47.0 / Claude 3.5 Sonnet 35.5——注意「出题人即考生」)、EgoPlan-Bench、RoboVQA、 Where2Place/RoboPoint/RefSpatial 指向套件、SAT(动态空间)、VSI-Bench/MMSI-Bench(视频与多图空间)、 PerceptionBench(原子视觉感知,2026-07)。问题:任务定义各家不同,榜单之间不可比; Google 把它们打包成 15-bench 聚合分,又引入了聚合口径的新问题。

8 · 解读:到底缺在哪,需要什么样的 bench

缺什么(按痛度排序)

  • ① 空间/3D 感知——所有路线的公共瓶颈。三份独立证据:VSI-Bench 人类 79.2% vs 当时最强 48.8%(2025 年 GPT-5 也才 55.0);MMSI-Bench 人类 97% vs GPT-5 40%;PerceptionBench 16 个前沿模型无一过 60%、幻觉是最弱项。 2026 年 Thinking with Spatial Code 给 4B LLM 接上真值 3D 空间编码后 VSI-Bench 直接到 73.2% 逼近人类—— 说明瓶颈在「眼睛」的 3D 感知质量,不在「脑子」的容量。所有 VLA 的大脑都建立在这块短板上。
  • ② 数据——结构问题大于量级问题。量级差 3–6 个数量级是真,但更致命的是:没有失败轨迹、没有触觉、人视频对不齐、license 碎片化。合成数据补量不补结构。
  • ③ 评测协议——没有公共尺度的领域谈不上工程进步。仿真被刷穿、真机无协议、感知层各自为政;「看见但不用」证明没有对照设计的 benchmark 会被文本先验蒙混。
  • ④ 长程与失败恢复。Claude「学的是动作序列不是规划器」、LIBERO 高分 2cm 归零、VLABench 全军覆没——纯模仿学习的天花板已被反复撞见;RL 后训练(π*0.6/GR-RL)刚起步,缺的是失败数据与奖励接口。
  • ⑤ 本体接口。人类视频、失败数据、遥操作纠正都变不成监督信号:缺 retargeting、缺奖励定义、缺跨本体动作空间(GR-3/RDT 的统一动作空间是早期尝试)。

那需要什么样的 benchmark(我的主张)

  • 感知层:可观测、可下钻、防蒙。按「能力 × 内容域 × 难度」切片报告,而不是一个聚合分;题目带难度梯度(别把模型全做对的题扔掉,那是观测能力涌现的唯一窗口);minimal pair(只差一个视觉事实,两题都对才给分)防猜测; 每道错题归因 first error——看错图、想错了、还是题出错了。PerceptionBench 的设计(隔离推理只测「看」+ 重复提问拆穿「猜对」)是这条路上目前最认真的公开样本,它「无模型过 60%」的结论应当成为所有具身大脑厂商的必读。
  • 认知/规划层:单步可判 + 视觉事实标注 + 去视觉对照。每道题标注「关键视觉事实」的标准答案,模型答错时才分得清是事实读错还是推理错;EmbodiedBench 的「去掉视觉输入重测」应该成为所有具身 QA bench 的标配对照——分数不降的题全部作废。
  • 执行层:真机 A/B + 部分进度分 + 统计规范。RoboArena 模式(双盲、ELO、0–100 进度分)值得扩大;所有成功率必须带 n 与置信区间;失败轨迹像 Eval-Actions 一样公开。「某厂商在某任务集 95%」这类数字在 2026 年应当失去引用资格。
  • 给从业者的「看数字」建议:看第三方可复现的(SimplerEnv、RoboChallenge、RoboArena)、看人机差距(PARTNR、OpenEQA)、看消融(去视觉、去 co-training、扰动 2cm)——不看厂商私有任务集的单次成功率。

2026 往后,看什么

  • 数据飞轮竞赛:部署密度(智元 5000 台、银河通用药店、1X 家庭、Figure BotQ)→ 失败回流 → 自动标注。这是中国玩家结构性有利、也唯一能对冲 frontier 模型差距的赛道。
  • RL 自改进:π*0.6 开了头,2026–27 的关键变量是「失败数据 + 奖励接口」谁先标准化。
  • 空间感知的军备赛:合成空间 QA(SpatialVLM/SpatialRGPT 路线)已被证明能缩差;RynnBrain 的原生 3D 定位、Qwen3-VL 的 3D grounding 都在补这一课。谁先让「眼睛」追平「嘴和手」,谁的分层架构才名实相符。
  • 评测层的公共品:具身领域缺一个「大家都认」的动作成功率协议——像 MMLU 当年对 LLM 那样。谁做出来,谁定义这个领域的进步叙事。
💡 对做感知评测的人的特别提醒:具身大脑的「大脑」全部建立在通用 VLM 上, 而通用 VLM 的原子感知(计数、空间关系、深度、幻觉)至今无人及格(PerceptionBench:最高 59.7%)。 也就是说,感知层 benchmark 的进步会线性地转化为具身系统的上限—— 这个领域少数「bench 改进能直接推动模型进步」的杠杆点,就在感知与空间这一层。
